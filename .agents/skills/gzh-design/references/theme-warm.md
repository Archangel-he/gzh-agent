# Warm：温暖叙事

适合生活随笔、旅途与人物故事；照片与原文叙事保持主导。建议底色 #fffdf8、正文 #3b352f、标题 #583f32、辅助 #72685d、强调 #9b654c、浅色 #f4ece0。正文16px/1.95，标题26px/1.45，章节19px/1.5，图注13px/1.7。纸感来自克制的色调和留白，不用不存在的纸纹图片或外部字体假装完成。

## 章节与取舍

使用 components 的正文与照片，统一替换为上述角色颜色。叙事顺序与照片表达一致；大段文字可在原有段落边界间安排真实配图，不拆碎原句或强行给每屏造标题。引语可用原有文本与温和侧线，少用厚底色框。长文只有一个主要视觉亮点即可，其余保持安静。不自动加抒情句、翻译英文、时间地点标签或摄影署名。
