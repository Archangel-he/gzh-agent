# Brief：清楚简报

适合技术教程、通知、知识与数据说明。建议底色 #ffffff、正文 #293441、标题 #203b56、辅助 #5b6979、强调 #326697、浅底 #eef3f8。正文16px/1.85，标题25px/1.4，章节20px/1.5，图注13px/1.7；代码可14px/1.7。避免把“科技”翻译成发光、深色霓虹和每段一张卡片。

## 标题区

```html
<section style="padding:12px 4px;color:#293441;">
<h1 style="margin:0 0 20px;font-size:25px;line-height:1.4;font-weight:700;color:#203b56;">文章原标题</h1>
<p style="margin:0 0 24px;font-size:16px;line-height:1.85;">原文已有的介绍或摘要。</p>
</section>
```

## 章节与取舍

使用 components 的正文、列表与表格。真实步骤才用编号；公告优先让时间、地点、报名条件易于找到，但不能重复编造一个要点摘要。代码和命令不润色，URL 保持原样。表格列太多时按项重排所有字段，避免小字挤成一团；公式和图表如需渲染为图片，只能在现有工具能力与素材上限内完成。强调一两个关键角色，不能每句加粗。
