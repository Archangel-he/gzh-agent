# Editorial：清晰刊读

适合观点、访谈与专业长文。正文承担信息，标题与真实照片建立识别。建议底色 #ffffff、正文 #303733、标题 #253b35、辅助 #646d67、强调 #547267；色彩可随用户参考调整。正文16px/1.9，章节20px/1.5，标题起点26px/1.4，图注13px/1.7。它们是初始值，长标题优先看断行，不一味缩小字号。

## 章节与取舍

使用 components 的章节、正文、照片、图注和引用。访谈以真实问答/引语组织；观点文以论证分节；没有章节标题的短文可连续排段，不擅加标签。保留充足段间距，真实引语用一条细侧线即可，不为每段画边框。结尾使用原文，取消无依据的作者签名、广告口号、二维码与关注引导。
